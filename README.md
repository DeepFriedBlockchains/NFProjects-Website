# Night Fantom Projects Website

Static GitHub Pages site featuring HOODRAT as the only announced project and an unnamed Upcoming Projects teaser. Other projects are intentionally confidential and are not referenced anywhere in the public page.

Files: index.html, style.css, script.js. Upload all three to the GitHub repository root. Set GitHub Pages to deploy from main / root.

Official social links and company/team emails are in the contact section. BitcoinTalk points to the forum homepage until a direct profile link is provided.

## Images
The website references the existing GitHub repository files `assets/nfprojects-logo.png` and `assets/hoodrat-artwork.png`. Keep the `assets` folder in place when uploading the updated HTML/CSS files.
