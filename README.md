# Night Fantom Projects Website

Static GitHub Pages site featuring the organization landing page. Features company logo design, information about NFP, its Projects and a dark minimal design. Currently, the HOODRAT token is the only announced and offically launched project listed on the page with plans to add their newest project just recently announced on BitcoinTalk. The NFP XTM-Miner Project is a APK/App for Android which has finally finished development and is currently undergoing extensive testing before its first offically release (TBD). The site also hints that multiple unnamed projects are under development, teasing them as upcoming projects. 

Some of those projects are intentionally confidential due to the amount of work that went into the research and development needed to make it into more than just an idea. NFProjects had stated multiple times that we are here to help advance digital software, specifically Digital Asset technologies. Advancements in development doesnt start with empty repositories, pretty pictures of templates and wild statements while never actually developing anything. 

We feel announcing a project concept before it has reached a point in development that it has continued to make progress, meaningful milestones & its followed up by testing that shows stability and doesnt continuously fail every test is just fake hype, proproganda & false hope. 
NFProjects and KasualLabz do not make promises. We make progress. Until project development has passed all initial goals, successfully completed multiple rounds of preliminary testing with little to no major issues or errors. Projects may be teased but wont be specifically mentioned or referenced anywhere in the public website page.

Files: index.html, style.css, script.js. Upload all three to the GitHub repository root. Set GitHub Pages to deploy from main / root.

Official social links and company/team emails are in the contact section. BitcoinTalk points to the forum homepage until a direct profile link is provided.
